# LNGS Fueling Platform

ລະບົບເຕີມນ້ຳມັນຜ່ານແອັບ: ລູກຄ້າສັ່ງ ແລະ ຈ່າຍໃນແອັບ → ພະນັກງານສະແກນ QR → ເຕີມນ້ຳມັນ → ຜູ້ຈັດການເບິ່ງທຸກຢ່າງແບບ real-time.

| ສ່ວນ | ເທັກໂນໂລຢີ | ໂຟນເດີ |
|---|---|---|
| ຖານຂໍ້ມູນ, Login, Real-time | Supabase (PostgreSQL) | `supabase/` |
| ລະບົບຈ່າຍເງິນ BCEL OnePay | Supabase Edge Functions | `supabase/functions/` |
| ແອັບລູກຄ້າ | React Native (Expo) | `fuel-customer-app/` |
| ແອັບພະນັກງານ | React Native (Expo) | `fuel-staff-app/` |
| Dashboard ຜູ້ຈັດການ | React + Vite | `fuel-dashboard/` |

**ເລີ່ມຕົ້ນ: ອ່ານ [DEPLOY.md](DEPLOY.md)** — ຄູ່ມືເປີດໃຊ້ງານຈິງ ເທື່ອລະຂັ້ນຕອນ.

## ຂັ້ນຕອນການເຮັດວຽກ

1. ລູກຄ້າເລືອກປໍ້າ (ໃກ້ສຸດຕາມ GPS) → ເລືອກນ້ຳມັນ ແລະ ຈຳນວນ → ຈ່າຍດ້ວຍ Wallet / BCEL OnePay / ເງິນສົດ
2. Server ຄິດໄລ່ລາຄາ, ສ້າງ QR (token ສຸ່ມ) + PIN 4 ໂຕ, ໝົດອາຍຸ 30 ນາທີ
3. ພະນັກງານສະແກນ QR ຫຼື ປ້ອນ PIN → ເລືອກຫົວຈ່າຍ → ອະນຸມັດ (ໜ້າຈໍລູກຄ້າປ່ຽນທັນທີ)
4. ເຕີມສຳເລັດ → ລູກຄ້າໄດ້ຄະແນນ (1 ຄະແນນ / 1,000 ກີບ), ຫົວຈ່າຍວ່າງຄືນ
5. Dashboard ເຫັນອໍເດີ, ຫົວຈ່າຍ, ຍອດຂາຍ ແລະ ພະນັກງານ ແບບສົດ

## ບົດບາດຜູ້ໃຊ້

| role | ໃຊ້ແອັບ | ສິດ |
|---|---|---|
| `customer` | ລູກຄ້າ | ສັ່ງ/ຍົກເລີກອໍເດີຂອງຕົນ, ເຕີມເງິນ |
| `staff` | ພະນັກງານ | ສະແກນ/ອະນຸມັດ ສະເພາະປໍ້າຂອງຕົນ |
| `manager` | Dashboard + ພະນັກງານ | ເບິ່ງທຸກປໍ້າ, ແກ້ລາຄາ, ແຕ່ງຕັ້ງພະນັກງານ |
| `admin` | Dashboard | ຄື manager + ແຕ່ງຕັ້ງ manager |
